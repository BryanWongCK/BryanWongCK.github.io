Scanji Translate

A Optical Character Recognition (OCR) translation tool built leveraging a locally hosted LLM Model. It primarily serves to translate Japanese text into English, with the default model being Qwen3-VL-8B. But can be used with other locally hosted models as well.

The tool features a customisable capture region, real-time translation capability with a variable polling interval, and image similarity threshold to avoid redundant translations.
